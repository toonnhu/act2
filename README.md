Este repositorio contiene el desarrollo de la Actividad 2 de la asignatura Ciencia de Datos. Su objetivo es practicar el uso de Git y GitHub para gestionar archivos, registrar modificaciones y mantener un historial de versiones.


Estructura del repositorio:
README.md: descripción del proyecto y registro de actividades.
documentos-txt/introduccion.txt: conceptos básicos de Git.
documentos-txt/comandos-git.txt: explicación de comandos básicos.
documentos-txt/procedimiento.txt: pasos realizados durante la actividad.
documentos-txt/conclusiones.txt: conclusiones del ejercicio.
Y se le agregaron documentos y pdfs.


Actividades realizadas:
Creación del repositorio act2 en GitHub.
Creación de archivos de texto.
Documentación de conceptos y comandos básicos de Git.
Registro de cambios mediante commits.
Sincronización del repositorio local con GitHub.


Comandos utilizados:
git status: consultar el estado de los archivos.
git add: preparar los cambios.
git commit: registrar los cambios.
git push: subir los cambios a GitHub.
git log --oneline: consultar el historial de commits.
